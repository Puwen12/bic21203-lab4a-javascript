## Project Overview
This repository contains the practical implementations for Lab 4a, demonstrating fundamental client-side scripting techniques. The project focuses on applying modern JavaScript to create interactive web elements and manipulate the Document Object Model (DOM) safely and effectively. 

**Key Implementations:**
* **Question1 (Interactive Text Changer):** Utilizes DOM selection methods and event listeners to dynamically update text content based on user interaction.
* **Question2 (Smart Number Validator):** Applies conditional logic (`if...else if...else`) and input sanitization to process, validate, and respond to user inputs.
* **Question3 (Dynamic Number Generator):** Uses `for` loops alongside `document.createElement()` to programmatically generate HTML list elements while preventing data duplication on repeated actions.
